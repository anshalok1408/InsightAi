## Movie RAG Assistant – Netflix / Movie Analysis

This project is an end‑to‑end **movie analytics and question‑answering system** built around a Netflix‑style movie dataset.  
It combines **data cleaning & analysis**, an optional **Power BI dashboard**, and a **Retrieval‑Augmented Generation (RAG) AI assistant** that lets you ask natural‑language questions about movies.

### Overview

- **Goal**: Turn a raw movie dataset into an interactive AI assistant that can answer questions such as:  
  *“Which 2019 action movies have the highest ratings?”* or *“Show me popular family movies with good reviews.”*
- **Core idea**: Use RAG to ground a Large Language Model (LLM) on your **own movie data**, so answers are both fluent and data‑driven.

### Features

- **RAG‑powered movie Q&A**
  - Ask questions in plain English about titles, years, genres, popularity, votes, and ratings.
  - Answers are generated by **Google Gemini** using context retrieved from your vector database.
- **Custom vector database**
  - Movie records are converted into rich text snippets and embedded with  
    `sentence-transformers/all-MiniLM-L6-v2` (HuggingFace).
  - Stored in a **FAISS** index for fast similarity search.
- **Streamlit web app**
  - Clean chat‑style UI with conversation history.
  - Sidebar configuration for **Gemini API key** and **model selection** (including custom models).
  - Helper action to list all Gemini models available for your key.
- **Data & analytics assets**
  - Cleaned CSV dataset for movies (`cleaned_mymoviedb.csv`).
  - Jupyter notebook for exploratory analysis (`Netflix Analysis.ipynb`).
  - Power BI dashboard (`Netflix Analysis Dashboard.pbix`) for visual exploration.

### Tech Stack

- **Frontend / App**: Streamlit
- **Embeddings**: HuggingFace `sentence-transformers/all-MiniLM-L6-v2`
- **Vector Store**: FAISS
- **LLM**: Google Gemini via `langchain-google-genai`
- **Orchestration**: LangChain (`RetrievalQA` chain)
- **Data / Analysis**: pandas, Jupyter Notebook, Power BI

### Project Structure

- **`Rag app/`**: RAG application source code  
  - `app.py` – Streamlit chat UI for the Movie RAG assistant  
  - `03_build_vector_db.py` – builds the FAISS vector database  
  - `04_rag_chain.py` – loads FAISS + Gemini into a `RetrievalQA` chain  
  - `Preprcoess.py` – loads and formats the movie CSV into LangChain `Document`s
- **`Data/`**: Raw and cleaned movie datasets (`mymoviedb.csv`, `cleaned_mymoviedb.csv`)
- **`faiss_index/`**: Saved FAISS index and metadata (`index.faiss`, `index.pkl`)
- **`Notebook/`**: Exploratory data analysis notebook (`Netflix Analysis.ipynb`)
- **`Dashboard/`**: Power BI dashboard (`Netflix Analysis Dashboard.pbix`)
- **`Root/requirements.txt`**: Python dependencies for the RAG app

### Setup

1. **Create and activate a virtual environment (recommended)**  
   On Windows (PowerShell):

   ```bash
   cd "Rag project - exp"
   python -m venv .venv
   .venv\Scripts\activate
   ```

2. **Install dependencies**

   ```bash
   pip install -r Root/requirements.txt
   ```

3. **Prepare the movie dataset**

- **Default expectation**: `Preprcoess.load_documents()` looks for `cleaned_mymoviedb.csv` in the current working directory where you run the scripts.  
- To match this repo layout you can either:
  - Copy `Data/cleaned_mymoviedb.csv` into `Rag app/`, **or**
  - Update the CSV path in `Preprcoess.py` to point to `../Data/cleaned_mymoviedb.csv`.

### Building the Vector Database

From the project root:

```bash
cd "Rag app"
python 03_build_vector_db.py
```

This will:

- Load the cleaned movie dataset via `Preprcoess.load_documents`
- Embed the documents using `sentence-transformers/all-MiniLM-L6-v2`
- Save the FAISS index into the `faiss_index/` directory

### Running the Streamlit App

1. **Set up your Google Gemini API key**

- Get an API key from `https://aistudio.google.com/app/apikey`.
- You do **not** need to set an environment variable; the key is entered directly in the Streamlit sidebar.

2. **Start the app** (from the project root or from inside `Rag app/`):

```bash
cd "Rag app"
streamlit run app.py
```

3. **In the browser UI**

- Enter your **Gemini API key** in the sidebar.
- Select or enter a **model name** (e.g. `models/gemini-2.5-flash` or a custom Gemini model).
- Ask any question about movies in the chat box.  
  The app will:
  - Retrieve relevant movie records from the FAISS index
  - Pass them to Gemini via a LangChain `RetrievalQA` chain
  - Display the generated answer in the chat.

### Notes

- **First run**: Make sure the FAISS index exists (run `03_build_vector_db.py`) before starting the Streamlit app, otherwise loading the RAG chain will fail.
- **Model errors**: If a model name is invalid or not available for your key, the sidebar button “List Available Models” can show the models your API key supports.
